# FrameBar releases

Тестовый Windows 11 x64 загрузчик файлов и папок в Frame.io: плавающая плашка, очередь, трей и команда Проводника.

**[Скачать установщик](https://github.com/igrikj/framebar-releases/releases/latest/download/FrameBar-Setup.zip)**

Распакуйте архив и запустите `Install.cmd`. Установка доверия локальному сертификату требует подтверждения администратора Windows. После установки настройте Adobe OAuth Native App и выберите папку Frame.io по умолчанию. Один Adobe/Frame.io аккаунт можно использовать на обоих компьютерах; очереди и настройки локальные.

## Приватность
Этот репозиторий содержит только установочные пакеты и описания версий. Пароли, OAuth-токены, очереди и настройки пользователя в релизы не включаются. Ввод пароля происходит на странице Adobe. Токены и очередь защищаются Windows DPAPI на каждом компьютере. Файлы загружаются напрямую в Frame.io.

`FrameBar-Local.cer` — открытый сертификат проверки подписи, без закрытого ключа. Кнопка клиентской ссылки создаёт публичный Frame.io Share для выбранного файла; не публикует файл в GitHub.

## Обновления
Постоянный канал: [FrameBar.appinstaller](https://github.com/igrikj/framebar-releases/releases/latest/download/FrameBar.appinstaller). Windows App Installer проверяет подписанные версии при запуске и в фоне. Понижение версии отключено. Для связи с каналом устанавливайте через `Install.cmd`, а не только двойным щелчком по MSIX.

## Статус
Предварительная сборка. Локальные автоматические проверки пройдены. Реальные операции Adobe/Frame.io, установка MSIX и обновление между версиями ещё требуют интеграционной проверки. Тестовый сертификат ограничен по сроку действия; при его смене может потребоваться повторное подтверждение доверия.

Исходный код здесь не публикуется.
